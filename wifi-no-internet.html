Wi-Fi Connected but No Internet: What to Check

Published September 2026 · Practical technology guide
Quick answerWhen Wi-Fi says 'connected' but the internet does not work, first determine whether the problem affects one device or several. Then check the local router connection, DNS/IP configuration, and the upstream internet service.

A quick isolation sequence

  • Test another device on the same Wi-Fi. If only one device fails, focus on that device rather than resetting the whole router.
  • Restart the affected device and, when appropriate, the router. Wait for the router's internet connection to return before testing again.
  • Try another website or service. One unavailable website does not necessarily mean the internet connection is down.
  • If multiple devices fail while the router reports an upstream problem, check the provider's status information or support channel before changing advanced network settings.

Test another device

If every device fails, investigate the router or broadband connection. If only one device fails, focus on that device.

Restart in the right order

Power down the modem/router as instructed by the provider, wait, and restart. Allow time for the connection to re-establish.

Check the connection status

Look for an IP address, gateway, and DNS information. A device can be connected to Wi-Fi while the router itself has lost internet access.

Try Ethernet if possible

An Ethernet test helps separate a wireless problem from a broadband problem.

Check the provider

If the router shows no WAN connection or multiple devices cannot reach the internet, check the provider's outage information or support channel.

Common mistakes to avoid

  • Restarting everything repeatedly without checking whether other devices have the same issue.
  • Assuming the Wi-Fi symbol means the internet connection is healthy.
  • Changing DNS settings before testing basic connectivity.
  • Factory-resetting the router before checking the ISP status or WAN connection.

Questions to check before you finish

What does 'connected, no internet' usually mean?

Your device has a local Wi-Fi link to the router, but it cannot reach the wider internet. The cause may be the router's WAN connection, DNS, ISP service, or the device itself.

How can I tell whether the outage affects only one device?

Test another device on the same Wi-Fi. If several devices fail, investigate the router or internet service; if one fails, focus on that device.

Should I change DNS first?

Not usually. First check the router's internet/WAN status and whether other devices can reach sites. DNS changes are more useful after basic connectivity has been established as the likely issue.
